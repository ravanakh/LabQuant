# QuantLab

QuantLab is a quantitative stock and portfolio analysis platform that runs multiple statistical models, simulations, and risk analyses for a selected stock or portfolio, then explains the results in plain English.

The platform combines historical market data with interactive TradingView charts to make quantitative analysis easier to understand and explore.

## Features

- Monte Carlo simulations
- Historical bootstrap
- Block bootstrap
- Student-t simulation
- EWMA modeling
- VaR and CVaR
- Sharpe and Sortino ratios
- Efficient frontier
- Portfolio optimization
- Model comparison
- Explanations of models and results
